隱私權政策

生效日期：2026 年 6 月 7 日

營運者：Walleaf 團隊｜聯絡信箱：support@walleafapp.com

Walleaf（以下稱「本 App」或「我們」）重視您的隱私。本政策說明我們如何處理與您使用本 App 相關的資訊。

核心原則：您的帳戶、交易、持倉、負債與大部分偏好設定預設儲存在您的裝置本機；除非您主動匯出備份，否則我們不會因一般記帳操作而將您的完整帳本上傳至雲端資料庫供我們讀取或代管。

1. 適用範圍

本政策適用於 Walleaf iOS 應用程式、為提供股價與匯率等機能而連線之後端服務，以及您透過 App 內連結造訪之政策網頁。本政策不適用於 Apple、iCloud、證券商、交易所或其他第三方服務之隱私作法。

2. 我們收集與處理的資訊

2.1 儲存在您裝置上的資訊

下列資料由您建立與管理，主要保存於裝置本機：

  • 帳戶名稱、帳戶類型、幣別；
  • 交易紀錄、持倉、成本、負債與其他資產資料；
  • 首頁走勢快取、資產配置、主題、主要幣別與介面偏好；
  • 首頁「隱藏金額」等隱私相關偏好；
  • 示範模式所使用之暫時性示範資料。

若您使用備份功能匯出 JSON 備份檔，檔案由您自行選擇儲存位置並保管。我們無法存取您的 iCloud 帳戶內容，亦無法替您還原遺失的備份。

2.2 為提供服務而傳送至後端的資訊

為取得報價、匯率及維持服務運作，本 App 可能向後端傳送必要且最小限度的資料，例如：

  • Supabase Anonymous Auth 建立之匿名使用者 ID 與存取權杖，用於 API 身分驗證、濫用防護與速率限制；
  • 資產類型與商品代號，用於查詢股價、歷史收盤、匯率與全站追蹤池；
  • IP 位址、請求時間、HTTP 狀態等伺服器日誌，用於資安防護、除錯與速率限制。

我們不會因一般記帳操作，將您的交易明細、帳戶餘額、持倉成本或淨資產完整上傳至雲端。

2.3 裝置權限

  • Face ID／Touch ID／裝置密碼：選用隱私鎖功能時，由 iOS 進行驗證。我們不收集、不儲存您的生物特徵資料。
  • 相簿：在您選擇儲存分享圖表時，將圖片寫入相簿。

2.4 訂閱與付款

Walleaf Plus 訂閱、付款、退款由 Apple App Store 處理。我們透過 Apple 提供之機制確認訂閱狀態，不自行保存您的信用卡號碼。訂閱綁定您的 Apple ID，與本機記帳資料 ID 無關。

3. 資料使用目的

我們使用上述資訊以提供記帳、資產彙總、損益與走勢顯示；查詢與快取報價、匯率；執行備份／還原；提供隱私鎖、主題與個人化設定；防範濫用與維護服務安全；回覆您的支援請求；以及遵守適用法律或主管機關合法要求。

4. 資料分享與第三方

我們不出售您的個人資料。我們可能與下列第三方共享有限資訊：

  • Supabase：API 請求、匿名 Auth、symbol 查詢，用於代管後端與 Edge Functions；
  • 報價與匯率資料來源：由後端代為查詢之商品代號，用於取得公開市場價格；
  • Apple：訂閱狀態、App 發行與 iCloud Drive 相關服務。

5. 資料保存與刪除

  • 本機資料保存於 App 沙盒，直至您刪除 App、還原覆蓋或自行清除資料。
  • 備份檔由您保管；刪除備份檔之責任由您自行承擔。
  • 後端匿名 Auth、API 日誌、symbol 追蹤等，依營運需要與後端設定保存一定期間後刪除或匿名化。

若您希望刪除與後端匿名 Auth 相關之資料，請來信 support@walleafapp.com，我們將依技術可行範圍協助處理。

6. 資料安全

我們採取合理之技術與組織措施保護傳輸與後端資料，例如 HTTPS、存取控管與速率限制。惟網際網路傳輸無法保證絕對安全；請妥善保管裝置、備份檔及 Apple ID。

7. 兒童隱私

本 App 非以未滿一定年齡之兒童為對象。我們不故意收集兒童個人資料。若您認為我們誤收兒童資料，請聯絡我們以便刪除。

8. 跨境傳輸

後端託管或資料處理可能位於台灣以外地區。使用本 App 即表示您理解必要資料可能於境外處理，並受當地法律及我們與服務提供者之安全措施保護。

9. 您的權利

依適用之個人資料保護法規，您可能享有查詢、閱覽、複製、補充、更正、停止處理或刪除等權利。請寄信至 support@walleafapp.com。我們將於合理期限內回覆。

10. 政策更新

我們可能因功能、法規或服務調整而更新本政策。重大變更將於 App 或官方網頁公告；更新後繼續使用本 App 即視為接受修訂內容。頁首「生效日期」將隨之更新。

11. 聯絡我們

若對本政策有任何疑問，請聯絡 support@walleafapp.com。
